# Changelog

All notable changes to Commons Fishery are documented here.

## 0.1.0 - 2026-09-01

- Added configurable multi-group, multi-round fishing sessions.
- Added timer and fuel season modes, resource presets, research, trade, boats, collapse outcomes, and cross-group rankings.
- Added persistent file and PostgreSQL storage.
- Added facilitator and participant sessions with role-specific game-state views.
- Added automated unit, build, browser, and multi-group load checks.
- Added Docker, Caddy, Render, and facilitator documentation for independent use.
